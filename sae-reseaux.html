Livrable 3

Audit du Portfolio

Analyse de l'intégration technique, de la responsivité, de l'ergonomie et de la valorisation des projets sur le site web.

Auto-évaluation Ergonomique

Le portfolio a été conçu à partir d'une feuille de style CSS native et d'architectures JS pures pour garantir une flexibilité et des performances maximales (Core Web Vitals optimisés).

✓
Responsivité Fluide (CSS Flexible Grid)

Le layout s'adapte automatiquement sur les smartphones, tablettes et écrans larges. Les vidéos et visionneuses 3D interactives sont encapsulées dans des conteneurs proportionnels (aspect-ratio 16/9).

✓
Accessibilité Numérique Intégrée

Mise en place d'un widget d'accessibilité en JS (`accessibility.js`) permettant aux utilisateurs de modifier la taille des caractères (A, A+, A++) ou de couper les animations. Idéal pour répondre aux normes RGAA.

✓
Mode Projecteur (Contraste Élevé pour Soutenance)

Création d'un style CSS dédié (`body.projector-mode`) qui élimine les ombres complexes, force un arrière-plan noir profond sans reflets et augmente la lisibilité des textes lors d'une projection sur tableau blanc en salle d'examen.

✓
Valorisation de Projets Avancée

Le portfolio utilise Google `model-viewer` pour intégrer des modèles GLTF interactifs en temps réel, permettant à l'utilisateur de manipuler les assets 3D (ex: l'Overbike) directement dans le navigateur.
